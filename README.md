# La Cucina - Restaurant Landing Page

A static restaurant website concept for **La Cucina**, an Italian dining brand. The project focuses on structuring a long-form landing page and styling it with plain HTML and CSS.

## Highlights

- Dark navigation bar with section links
- Restaurant hero section with primary calls to action
- About and restaurant-story section
- Menu presentation with dish descriptions and prices
- Specials, gallery, reviews, and contact-oriented page sections
- Gold accents, responsive layout techniques, and hover states

## Tech Stack

- HTML5
- CSS3
- Remote placeholder images from Picsum

## Run Locally

No build tools or package installation are required.

```bash
git clone https://github.com/Coderudit05/restaurant-landing-page-project-sca.git
cd restaurant-landing-page-project-sca
```

Open `index.html` in your browser. For a smoother development workflow, use the VS Code Live Server extension.

## Design Notes

The page uses a dark charcoal base, warm white surfaces, and gold accents to create a premium restaurant aesthetic. The content is organized into semantic page sections and navigated through in-page anchor links.

## Limitations

This is a **static front-end concept**. Reservation links and contact calls to action are visual/navigation elements; no booking backend or form submission service is included. Some images are remote placeholders and require an internet connection. Replace sample restaurant details and imagery before presenting it as a real business website.
